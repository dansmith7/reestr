# Контекст проекта «Реестровые записи — статус»

## Где что находится

- Репозиторий: `https://github.com/dansmith7/reestr`
- Рабочая ветка: `main`.
- Production-сайт: `https://reestr-five.vercel.app/index.html`
- Хостинг: Vercel. Production должен обновляться от push в `main` через Git-интеграцию; не создавайте новый Vercel-проект для очередного деплоя.
- Исходный код приложения: эта папка (`vercel-version/`).
- Интерфейс: `public/index.html`; корневая Next.js-страница перенаправляет на `/index.html`.

## Данные и окружение

- База данных: Neon Postgres, подключённая к production-проекту Vercel.
- Строка подключения доступна на Vercel в переменной `POSTGRES_URL` (также поддерживаются `DATABASE_URL` и `POSTGRES_PRISMA_URL`). Не добавляйте её в репозиторий.
- Важные таблицы: `projects`, `stages`, `status_log`.
- Каждое обновление статуса добавляет запись в `status_log` с датой действия (`effective_date`); история не перезаписывается.

## Этапы по умолчанию

1. Обсуждение условий проекта
2. Подготовка КД
3. Производство тестовой партии и подготовка КД
4. Производство тестовой партии завершено
5. Подготовка КД завершена
6. Заявка в ГИСП подготовлена
7. Заявка в ГИСП подана
8. Камеральная проверка
9. Камеральная проверка пройдена
10. Камеральная проверка на одобрении ЦА ТПП
11. Планирование выездной проверки
12. Выездная проверка завершена
13. Акт экспертизы готовится
14. Акт экспертизы подготовлен
15. Акт экспертизы на рассмотрении в МПТ
16. Реестр получен

## Сравнение дат

- API: `pages/api/compare.js`.
- Для корректного сравнения проект должен иметь запись `status_log` на дату исходного среза и более позднюю запись на дату нового среза.
- Отсутствие исторической записи не должно считаться «новым проектом», если проект был создан раньше даты сравнения: интерфейс должен показывать «нет среза на дату сравнения».

## Фавикон

## Проверки и публикация

- Перед коммитом: `node --check pages/api/compare.js` и `git diff --check`.
- Для публикации: сначала commit, затем `git push origin main`; Vercel должен задеплоить изменения автоматически.
- Не публикуйте новый отдельный Vercel-проект вместо production-проекта `reestr-five`.
